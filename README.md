# Animalitos API

Esta es una API desarrollada con Node.js y Express para la gestión de clientes en una veterinaria.

## Tecnologías utilizadas
* Node.js
* Express
* MySQL (o la base de datos que estés usando)
* Dotenv (para variables de entorno)

## Estructura del Proyecto
* `src/controllers`: Lógica de las rutas.
* `src/routes`: Definición de los endpoints.
* `src/db`: Configuración de la conexión a la base de datos.
* `app.js`: Punto de entrada de la aplicación.

## Instalación y Ejecución

1. Clonar el repositorio.
2. Instalar dependencias: npm install
3. Crear un archivo .env basado en las necesidades del proyecto (ej: DATABASE_URL, PORT).
4. Iniciar el servidor: npm start.
